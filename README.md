# LifeHub prototype

Prototip estàtic d'una web app per centralitzar:
- Subscripcions
- Compres i garanties
- Assegurances
- Manteniments
- Dominis i serveis digitals
- Agenda global de venciments

## Com obrir-lo

1. Descomprimeix la carpeta.
2. Obre `lifehub-prototype` amb Visual Studio Code.
3. Obre `index.html` directament al navegador, o fes servir l'extensió **Live Server**.
4. No necessita instal·lar cap dependència.

## Fitxers

- `index.html` — estructura
- `styles.css` — disseny
- `app.js` — dades fictícies, filtres i navegació

És només un prototip frontend: no desa dades ni té backend.
